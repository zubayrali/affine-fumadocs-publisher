# Wiki feature baseline

The template currently includes Fumadocs search and machine-readable routes,
native AFFiNE publication properties, custom page properties, hierarchical tag
browsing, AFFiNE document-link rewriting, backlinks, orphan detection, hover
link previews, article lightbox galleries, and AFFiNE database table / gallery /
kanban views.

## AFFiNE document links

AFFiNE exports LinkedPage references as Markdown links such as
`[Guide](/workspace/<workspaceId>/<docId>)`. The publisher rewrites published
targets to public `/docs/...` routes and records `outgoingLinks` for backlinks.
Obsidian `[[wikilink]]` syntax is not supported.

Hover a published internal link like [Welcome](/docs) to preview its content.

## Lightbox and databases

See the [media fixtures](/docs/media) page for click-to-enlarge images and a
sample database with table, board, and gallery views. Feature flags live in
`affine-wiki.config.ts` (`lightbox`, `databases`).

## Still in progress

Body-level note transclusion is deferred: AFFiNE's Markdown export flattens
embed-linked documents into the same link form, so the snapshot cannot recover
embedded bodies yet. Graph, reader tools, canvas, multilingual homepage
controls, and Publishing Studio remain later vertical slices.
