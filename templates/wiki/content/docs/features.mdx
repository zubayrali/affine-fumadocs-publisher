# Wiki feature baseline

The template currently includes Fumadocs search and machine-readable routes,
native AFFiNE publication properties, custom page properties, and hierarchical
tag browsing. The remaining feature modules are tracked in the repository's
wiki template specification and are being added as tested vertical slices.
