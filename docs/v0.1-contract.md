# v0.1 contract

The publisher accepts an explicit configuration object and emits a local
snapshot. Its configuration never embeds a user workspace ID, website name, or
filesystem convention. The output contract is:

```text
<output>/content/**/*.mdx
<output>/public/affine-blobs/*
<output>/manifest.json
<output>/diagnostics.json
```

v0.1 supports AFFiNE documents, native publishing properties/tags, AFFiNE-native
document links (`[title](/workspace/<id>/<docId>)`), and blob-backed images.
Obsidian `[[wikilink]]` syntax is out of scope. Edgeless, Bases, database views,
and body-level note transclusion require a diagnostic and fallback rather than
being advertised as rendered content.
